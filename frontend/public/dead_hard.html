1. Les Fonctions : Comprendre les Relations Mathématiques

1.1 Qu'est-ce qu'une Fonction ?

Une fonction est une relation qui associe à chaque valeur d'entrée (appelée variable indépendante) une seule valeur de sortie (appelée variable dépendante). Pensez à une fonction comme une machine qui prend un ingrédient (l'entrée) et produit un produit (la sortie).

Exemple :

  • Si on entre 3, la machine sort 5.
  • Si on entre 7, la machine sort 9.

Mathématiquement :

  • \(f(3) = 3 + 2 = 5\)
  • \(f(7) = 7 + 2 = 9\)

1.2 Notation et Représentation des Fonctions

  • Notation fonctionnelle : \(f(x)\) signifie la fonction \(f\) évaluée en \(x\).
  • Variable indépendante : \(x\) (l'entrée).
  • Variable dépendante : \(y = f(x)\) (la sortie).

Les fonctions peuvent être représentées graphiquement en traçant des points \((x, y)\) sur un plan cartésien. Cela permet de visualiser comment la fonction se comporte.

1.3 Types de Fonctions Courantes

Les fonctions sont des outils fondamentaux en mathématiques, et il existe plusieurs types de fonctions qui apparaissent fréquemment. Comprendre ces fonctions et leurs caractéristiques est essentiel pour progresser en calcul.

1.3.1 Fonctions Linéaires

Définition : Une fonction linéaire est une fonction de la forme :

\(f(x) = mx + b\)

  • \(m\) est le coefficient directeur ou pente de la droite.
  • \(b\) est l'ordonnée à l'origine, c'est-à-dire le point où la droite coupe l'axe des ordonnées (\(y\)).

Caractéristiques :

  • Le graphique d'une fonction linéaire est une droite.
  • Si \(m > 0\), la droite est croissante (monte de la gauche vers la droite).
  • Si \(m < 0\), la droite est décroissante (descend de la gauche vers la droite).
  • Si \(m = 0\), la fonction est constante et la droite est horizontale.

1.3.2 Fonctions Quadratiques

Définition : Une fonction quadratique est une fonction de la forme :

\(f(x) = ax^2 + bx + c\)

  • \(a, b,\) et \(c\) sont des constantes réelles.
  • \(a \neq 0\) pour assurer que le terme en \(x^2\) est présent.

Caractéristiques :

  • Le graphique d'une fonction quadratique est une parabole.
  • Si \(a > 0\), la parabole s'ouvre vers le haut.
  • Si \(a < 0\), la parabole s'ouvre vers le bas.
  • Le sommet de la parabole est le point où la fonction atteint son maximum ou minimum.

1.3.3 Fonctions Exponentielles

Définition : Une fonction exponentielle est une fonction de la forme :

\(f(x) = a^x\)

  • \(a\) est une constante positive différente de 1 (\(a > 0\) et \(a \neq 1\)).
  • La variable \(x\) est à l'exposant.

Caractéristiques :

  • Si \(a > 1\), la fonction est croissante.
  • Si \(0 < a < 1\), la fonction est décroissante.
  • Le graphique passe toujours par le point \((0, 1)\) puisque \(a^0 = 1\).

1.3.4 Fonctions Logarithmiques

Définition : Une fonction logarithmique est la fonction inverse d'une fonction exponentielle, de la forme :

\(f(x) = \log_a x\)

  • \(a\) est la base du logarithme (\(a > 0\) et \(a \neq 1\)).
  • La fonction est définie pour \(x > 0\).

Caractéristiques :

  • Si \(a > 1\), la fonction est croissante.
  • Si \(0 < a < 1\), la fonction est décroissante.
  • Le graphique passe par le point \((1, 0)\) puisque \(\log_a 1 = 0\).

1.3.5 Fonctions Trigonométriques

Définition : Les fonctions trigonométriques sont liées aux angles et aux triangles, notamment dans le cercle unité.

Les principales fonctions sont :

  • Sinus : \(f(x) = \sin x\)
  • Cosinus : \(f(x) = \cos x\)
  • Tangente : \(f(x) = \tan x\)

Caractéristiques :

  • Périodicité : Les fonctions sinus et cosinus sont périodiques de période \(2\pi\).
  • Amplitude : Les valeurs de \(\sin x\) et \(\cos x\) sont comprises entre \(-1\) et \(1\).
  • Points remarquables :
    • \(\sin 0 = 0, \sin \frac{\pi}{2} = 1\)
    • \(\cos 0 = 1, \cos \frac{\pi}{2} = 0\)

1.3.6 Fonctions Réciproques

Définition : Une fonction réciproque est une fonction qui "annule" l'effet d'une autre fonction. Si \(f\) est une fonction bijective, alors sa réciproque \(f^{-1}\) est définie par :

\(f^{-1}(f(x)) = x\)

Exemples :

  • La fonction exponentielle \(f(x) = e^x\) a pour réciproque la fonction logarithme naturel \(f^{-1}(x) = \ln x\).
  • La fonction carré \(f(x) = x^2\) (pour \(x \geq 0\)) a pour réciproque la fonction racine carrée \(f^{-1}(x) = \sqrt{x}\).

1.3.7 Fonctions Absolues

Définition : La fonction valeur absolue est définie par :

\(f(x) = |x| = \begin{cases} x, & \text{si } x \geq 0 \\ -x, & \text{si } x < 0 \end{cases}\)

Caractéristiques :

  • Le graphique est en forme de "V", avec un minimum à \(x = 0\).
  • La fonction est toujours positive ou nulle.
  • Elle est continue sur \(\mathbb{R}\).

Exemples :

  • \(f(-3) = |-3| = 3\)
  • \(f(2) = |2| = 2\)
  • \(f(0) = |0| = 0\)

1.3.8 Fonctions Racines

Définition : Une fonction racine est une fonction qui associe à un nombre son radical (racine).

Exemple :

  • Racine carrée : \(f(x) = \sqrt{x}\), définie pour \(x \geq 0\).
  • Racine cubique : \(f(x) = \sqrt[3]{x}\), définie pour tout \(x\).

Caractéristiques :

  • Racine carrée : Le graphique est une courbe qui commence à \(x = 0\) et augmente lentement.
  • Racine cubique : Le graphique passe par l'origine et est symétrique par rapport à l'origine.

1.3.9 Fonctions Rationnelles

Définition : Une fonction rationnelle est le quotient de deux polynômes :

\(f(x) = \frac{P(x)}{Q(x)}\)

  • \(P(x)\) et \(Q(x)\) sont des polynômes.
  • La fonction n'est pas définie là où \(Q(x) = 0\).

Caractéristiques :

  • Asymptotes verticales : Là où \(Q(x) = 0\).
  • Asymptotes horizontales ou obliques : Déterminées par les degrés de \(P(x)\) et \(Q(x)\).

Exemple :

\(f(x) = \frac{1}{x}\)

  • Non définie en \(x = 0\).
  • Asymptotes verticales à \(x = 0\).
  • Asymptote horizontale à \(y = 0\).
