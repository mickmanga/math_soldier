Introduction aux statistiques

1) La moyenne

Définition : La moyenne (arithmétique) est la somme de toutes les valeurs divisée par le nombre total de celles-ci.

Exemple : Pour cinq notes : 12, 14, 10, 8 et 16, la moyenne est 12 + 14 + 10 + 8 + 16 5 = 12. 5 12+14+10+8+16 ​ =12.

2) La médiane

Définition : La médiane est la valeur centrale d’une série de données lorsqu’elles sont ordonnées. Comment la calculer : Si le nombre de valeurs est impair, la médiane est la valeur du milieu. Si le nombre de valeurs est pair, la médiane est la moyenne des deux valeurs centrales.

Exemple : Pour la série ordonnée 8, 10, 12, 14, 16 (cinq valeurs), la médiane est la troisième valeur, soit 12. Pour la série 8,10,12,14 => la médiane sera la moyenne de 10 et 12, donc 11.

3) Les pourcentages

Définition : Les pourcentages expriment une proportion sur 100. Ils permettent de comparer des fractions de quantité (par exemple, 45 % de personnes satisfaites sur un échantillon). Ils se calculent souvent à partir d’une fraction en multipliant par 100 (par exemple, 45 100 × 100 = 45 % 100 45 ​ ×100=45%).

4) Le mode

Définition : Le mode est la valeur la plus fréquente dans une série de données. Exemple : Dans la série 12, 14, 14, 10, 8, 16, 14, le mode est 14, car c’est la valeur qui apparaît le plus souvent.

5. L'étendue

Définition : L’étendue est la différence entre la valeur la plus grande et la valeur la plus petite d’un jeu de données. Utilité : Elle donne une première idée de la dispersion des données. Exemple : Si les données vont de 8 à 16, l’étendue est 16 − 8 = 8 16−8=8.
